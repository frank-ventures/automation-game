# Queue Zero - the awfully named Automation game

Teaching the concept of Automation?

Need a 5 minute interactive and visual explainer?

Queue Zero might be for you.

## What?

Doing stuff can be tedious.

Doing boring, tedious stuff is even tediouser.

Let your students **feel** that and **really experience it** by dragging and dropping customer data into the right location _(I was going to make them type it but this is a game after all)_

They might make mistakes and get bored - that's the point.

**But then......Automation!**

They'll get to set up a workflow then see the 'automation' in action, saving them precious clicks, time and repetitive strain injury.

## Why

I couldn't find a simple visual game which allowed a "new to the concept" student to get their hands on quickly.

Something like Zapier could do this, but, you'd need to sign up, log in, navigate the UI, understand what 'Zap' means, click the right things, link things....I'm already bored.
